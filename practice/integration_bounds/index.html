Limits of a double integral

Problem Set 2 asks you to integrate over regions that are not rectangles. This page checks one move: reading the limits off a region, in the order you need.

About 3 minutes if you remember it. About 10 if you use the reminder.

Start with the task below. If you get it right, you are done.

Try this first

A region is described by 0 < x < 2 and x/2 < y < 1. That description suits integrating over y first.

Write the limits for integrating over x first. Limits may use numbers, x and y, for example 3y or 1 - x/2.

Reminder

Use as much of this as you need. Nothing here is scored.

    Show the full worked explanation
    1. Integrating over x first means holding y fixed. Picture a horizontal slice across the region at height y.
    2. The slice enters the triangle through its left edge, the line x = 0. The lower inner limit is 0.
    3. The slice leaves through the slanted edge, y = x/2. The inner variable is x, so solve that edge for x: x = 2y. The upper inner limit is 2y.
    4. Slices cross the triangle for heights between 0 and 1. Those numbers are the outer limits.
    ∫01 ∫02y f(x,y) dxdy

    A quick check: with f = 1, both orders give the triangle's area, 1.

    Extension: when the slice changes edge

    Optional. Some regions need one more idea: partway across, the slice starts leaving through a different edge.

    A region is described by 0 < y < 1 and y < x < 2 − y. Write the limits for integrating over y first.

    1. As a vertical slice moves from left to right, does it leave the region through the same edge the whole way?
    2. How will you write the limits?

    The slice is now above the figure. Move it across the middle of the region and watch which edge it leaves through.

    Show the full worked explanation
    1. Integrating over y first means holding x fixed: a vertical slice. Every slice enters through the bottom edge, so the lower inner limit is 0.
    2. Left of x = 1, the slice leaves through x = y. Solved for y, that is y = x.
    3. Right of x = 1, it leaves through x = 2 − y, which is y = 2 − x.
    4. The exit edge changes at x = 1, so split the integral there. Or keep one integral and write the upper limit as whichever edge is lower: min(x, 2 - x).
