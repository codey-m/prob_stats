# Probability & SDA optional reviews

Ungraded activities that run in the browser, with reminders and practice that unfolds as you work. No programming is needed, and nothing is recorded. Each link opens the page on GitHub Pages.

## Math refreshers

Each refresher checks one piece of mathematics that the problem sets use, then offers a reminder if you need it. The second column lists the problem sets that use it. Course codes are shortened: 2x is `6.3710.2x`.

| Math refresher | Used in | What you practice |
| --- | --- | --- |
| [Calculus check for Problem Set 2](https://codey-m.github.io/prob_stats/practice/ps2_calculus_check/) | 2x Problem Set 2 | Try one short task for each piece of calculus the set uses, and open the refresher for any you miss. |
| [Limits of a double integral](https://codey-m.github.io/prob_stats/practice/integration_bounds/) | 2x Problem Sets 2 and 3; 3x Problem Set 1 | Set the limits for integrating over a region in the other order. |
| [Integrating a density](https://codey-m.github.io/prob_stats/practice/density_integrals/) | 2x Problem Sets 2 and 3; 3x Problem Sets 2 and 3 | Evaluate an antiderivative at the limits and find a normalizing constant. |
| [Finding a maximum or minimum](https://codey-m.github.io/prob_stats/practice/max_min/) | 2x Problem Set 2; 3x Problem Sets 2 and 3; 4x Problem Set 2 | Take logs, set the derivative to zero, and check the sign change and the allowed range. |
| [Limits as something grows](https://codey-m.github.io/prob_stats/practice/limits/) | 2x Problem Set 2; 3x Problem Set 3; 4x Problem Set 1 | Find the fastest-growing term and see what it leaves behind. |
| [The chain rule](https://codey-m.github.io/prob_stats/practice/chain_rule_cdf/) | 3x Problem Set 1 | Differentiate a CDF whose argument is itself a function. |

## Spiral reviews

Each spiral review revisits a method from an earlier unit, for use across the unit you are starting.

| Spiral review | What you practice |
| --- | --- |
| [Spread and precision](https://codey-m.github.io/prob_stats/practice/spread_and_precision/) | Distinguish individual variation from the precision of a sample mean. |
| [Conditioning and independence](https://codey-m.github.io/prob_stats/practice/conditioning_and_independence/) | Retain cases matching a known event and normalize their probabilities. |
| [Variance of sums and averages](https://codey-m.github.io/prob_stats/practice/variance_of_sums/) | Track shared components and account for covariance and scaling. |
| [Posterior summaries](https://codey-m.github.io/prob_stats/practice/posterior_summaries/) | Choose estimates for exact matches or squared error, and retain uncertainty. |
| [Combining conditional results](https://codey-m.github.io/prob_stats/practice/total_probability_and_expectation/) | Weight within-group results to recover population probabilities and means. |
| [Comparing likelihoods](https://codey-m.github.io/prob_stats/practice/likelihood_and_fit/) | Compare candidate means using the same observations. |
| [Counting successes](https://codey-m.github.io/prob_stats/practice/binomial_counts/) | Build sequence probabilities and count arrangements of successes. |
